# AI 单任务投入账本

## 定位

这是一个断网可用的本机账本。它把每个 AI 任务的人工工作、返工、API 费用、订阅额度观察和验收结果放在一条记录中，同时保留各自口径。

双击 `index.html` 即可使用。地址加 `?today=2026-10-29` 可固定基准日，页面会持续显示该日期。

## 目标用户

首位使用者是 Tony。适合需要比较同类 AI 任务投入，但不希望接入账号、账单 API 或云服务的个人使用者。

## 核心口径

- 工作分钟是第一次完成任务的人工时间；返工分钟是修复、重做和复验，不应重复计入工作分钟。
- API 费用可明确选择未知。未知值不进入金额合计，也不显示为 0。
- 已知 API 费用和人工成本按币种分别合计。账本不换汇。
- 订阅额度只记录页面观察值。百分点、token、请求数、额度点数和金额互不换算。窗口重置或不可比时不计算差值。
- 人工成本只在使用者填写时薪后估算。
- 同类任务只显示验收通过样本的总耗时中位数、全部样本数和通过样本数。这是描述性记录，没有“未使用 AI 的同类基线”时不能解释为因果节省。

## 数据与导出

数据保存在浏览器 `localStorage` 的 `taskEffortLedger.v1`。提供 JSON 完整备份、CSV 任务明细和 Markdown 报告。JSON 导入先整份校验，再显示数量和示例身份，最后由使用者确认替换。

载入示例后，每条示例会持续标记为“合成示例”并进入导出。新增本人记录不会改变其余示例的身份；编辑示例也保留其原始身份。总览指标只统计本人记录。

## 证据来源

产品方向来自本机报告 `20261025-0828-抱怨雷达近期20项产品机会与开发验证.html` 中的“AI 单任务投入账本”。报告把它列为待验证候选，并明确交易证据为 0。本实现没有真实使用记录，也没有付款证据；它只用于门 1 的本人试用。

## 已知限制

- 时间、时薪、费用和验收结果都由使用者手工填写。
- 不自动读取模型用量和账单；浏览器清除站点数据会删除记录，因此需要定期导出 JSON。
- 不计算统计显著性，也不评价模型优劣。
- “其他”额度单位由使用者自行定义，仍只用于观察。
